# Country Info App

A simple web application that lets you search for a country and see its basic information.

## Features
- Search for any country by name
- Displays country name
- Displays capital city
- Displays the country flag
- Loading state while fetching data
- Error handling for not found countries

## Technologies Used
- HTML
- CSS
- JavaScript (Fetch API, async/await, DOM manipulation)

## How to Use
1. Open `index.html` in your browser (or use Live Server)
2. Type a country name (e.g. Germany, France, Japan)
3. Click Search or press Enter
